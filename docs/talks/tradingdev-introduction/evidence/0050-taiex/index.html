這次實際觀察到的流程

  • 開場只提供均線與0050構想；Sol 先追問期間、頻率與規則，未提早建立策略或回測。
  • 操作者沿用原案例的期間、20日SMA與成本，明確指定相等維持原部位及252年化因子；第三輪準備確認單。
  • 確認單以UTC顯示台灣日期邊界；第四輪解釋時區與年化，第五輪在暫停後查詢仍有效的原確認單，未建立新計畫。
  • 第六輪明確同意後只執行一次歷史回測，共118根日K、5筆已平倉與1筆未平倉，策略報酬24.33%、最大回撤8.61%。
  • 第七輪讀取保存報告的基準資料：台股加權指數^TWII完整對齊118/118根，報酬29.01%、最大回撤6.66%；這是價格指數、非含息總報酬或0050買進持有。
  • 報酬落後大盤4.68個百分點，回撤多1.95個百分點；標的成分不同，不能將全部差距歸因於均線擇時。緩衝區僅為未驗證建議，沒有新增回測。
  • 第八輪才依要求保存與匯出研究筆記，第2版附完整原生報告；更正早期同資料措辭，原版報告另外保留，不改寫歷史。
  • 第一次研究包匯出因附件類型不支援而失敗；Sol 依工具錯誤修正附件，保存筆記第2版並成功匯出。完整可見紀錄保留失敗與修復。
