資金、交易成本與執行設定

訊號與成交時點：訊號延後一根 K 棒，一般訊號進出場使用下一棒 open；缺少 open 欄位才使用 close。尚未平倉部位以當棒 close 評價。

多空與零訊號：1 表示做多，-1 表示做空（不是只賣出平多倉）。0 表示平倉。

反向訊號：相反的非零訊號平掉舊方向並嘗試建立新方向；停損停利先於訊號處理。

投入金額：未指定固定金額，以當時可用資金及成交成本決定最大可成交數量；不是固定數量或固定初始本金比例。

部位權重：此模式不使用部位權重。

同方向持倉：持續相同方向的訊號不加碼。

資金與槓桿限制：不模擬完整保證金、清算、借券或資金費率規則，也沒有固定槓桿倍數設定。多倉受可用現金限制；固定金額空倉不鎖定現金，不能據此聲稱沒有槓桿或保證百分之百成交。

停損停利成交：停損 未設定；停利 未設定。以進場棒 close 為基準，後續只用 open/close 的高低範圍判斷，不使用行情 high/low；停損優先於停利與一般訊號。跳空跨過門檻時以 open 出場，否則以門檻價出場；零值是零距離停損停利。新倉不在進場當棒檢查停損停利。

停損停利後進場：停損停利平倉後不在同棒重新進場，須有後續持倉訊號狀態變化才可能進場；重新進場開關不影響此模式。

成交成本：手續費率 0.06%；滑價率 0.05%。各成交收取手續費，一般訊號的滑價反映於成交價。停損停利採 stoplimit 模擬，出場滑價為零。

年化解讀：使用觀測到的 UTC 日報酬，缺日不補值；須有有效時間戳及不粗於日線的資料。保存的每年日數為 252。年化無風險利率 0%；年化最低目標報酬 0%。

每月虧損限制：此模式不使用每月虧損限制。

資料結束時：剩餘持倉保留為未平倉，以最後 close 評價，不虛構出場成交。

規則與檢查的限制：以上是模擬引擎規則，不是策略 Python 或 ML 決策的形式證明。本快照不證明合成檢查已通過、策略符合構想、沒有未來資料或歷史績效有效；確認前的合成檢查證據須另行查看，正式資料與績效仍須於授權後執行。
