4. 解讀限制

本次只有118根日K與極少已平倉交易，未做樣本外或市場型態驗證；診斷提示樣本少，屬啟發式檢查，不證明績效原因。60日均線暖機較久，三組實際可交易期間不同，不能把績效差距全歸因於均線反應速度。成本尚未另計ETF證交稅、券商最低手續費與整股限制；Yahoo價格還原、分割與配息處理未獨立核實，歷史價格及數量不可直接視為當時券商報價與整股委託。252日年化只是假設，半年年化結果不代表全年可達成。本研究不支持直接宣稱5/20日長期最優或均線能穩定勝過大盤。

建議先補上同資料與成本的0050買入持有基準，區分標的成分差異與均線擇時效果；提供評估起點之前的足夠暖機資料，統一三組評估起點；拉長至涵蓋不同行情的多年期間並保留獨立資料做樣本外驗證。可保留5/20日作研究起點，另測短均線連續兩天低於長均線才賣出的版本，入場仍依原規則；假設是減少短暫跌破造成的換手，但退出會較慢，也可能承受更大跌幅，效果未驗證。每次只變動一項規則，並以報酬、最大回撤、交易次數及成本敏感度評估。以上均為提案，尚未建立或執行新回測；使用者此次授權為整理與匯出既有研究。
